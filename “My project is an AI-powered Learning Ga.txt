“My project is an AI-powered Learning Gap Detection System designed to identify students’ weak concepts and provide personalized learning recommendations. The main objective of the project is to go beyond traditional scoring systems and analyze the actual learning gaps of students. I developed the project using Python, Streamlit, SQLite, OpenRouter GPT API, Pandas, Matplotlib, and Graphviz. In this system, users first log in and select a topic, difficulty level, and number of questions. The application then retrieves relevant learning context from the dataset using RAG and semantic search concepts, and the GPT model dynamically generates multiple-choice questions. After the student submits answers, the system evaluates performance using rule-based logic, identifies weak areas, stores scores in the database, and generates personalized learning roadmaps for improvement. The project also provides analytics dashboards, quiz history, performance charts, and visual learning flowcharts. Through this project, I gained hands-on experience in Generative AI, prompt engineering, vector retrieval, adaptive learning systems, and full-stack AI application development.”
